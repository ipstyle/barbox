What it does

One window, everything you reach for a dozen times a day.

Live stats

CPU, memory and GPU usage right in the header. Battery, Wi-Fi and Bluetooth status at a glance, each as a dropdown.

Files & text

  • Image compression (AI preset, half size)
  • Text from image — OCR, on-device
  • Merge PDFs, batch rename, QR codes

Everyday helpers

  • Keep awake, timer with notification
  • Clipboard history (memory only)
  • Password and UUID generator

Info at a glance

  • Local and public IP, speed test
  • CHF → EUR/USD, SARON, SNB policy rate
  • Weather with a 5-day forecast

Your layout

Favorites, app launcher, volume and audio output. Every section collapsible and reorderable, window size adjustable.

Two languages

English and German interface, switchable in the settings — takes effect immediately, no restart.

Install

Two ways to get it — same source code, one difference.

From the Mac App Store

Sandboxed, signed by Apple, updates by itself. The recommended way for most people. Open in the App Store →

Or straight from GitHub

Same app, plus what the sandbox does not allow: display brightness, Wi-Fi and Bluetooth switches, AirDrop, Time Machine and the speed test.

  1. Download BarBox-x.y.zip from the latest release and unzip it.
  2. Move BarBox.app to your Applications folder.
  3. First launch: the GitHub build is not notarized — right-click the app → Open → Open. Or, in Terminal:
xattr -d com.apple.quarantine /Applications/BarBox.app

How I build

Every claim on this page can be checked against the source — that is the point of shipping it open.

At rest

BarBox stores nothing sensitive: your settings sit in the app’s own preferences, your favorites in a small file next to them. No accounts, no passwords, no keychain items, no database. The clipboard history lives in memory only and is gone when you quit.

In transit

Four hosts over HTTPS, all of them public services, none of them mine: api.open-meteo.com for weather, api.frankfurter.dev for rates, data.snb.ch for Swiss interest rates, and api.ipify.org only when you click. No identifier travels with them.

Nothing comes back to me

No analytics, no crash reporting, no telemetry, no third-party SDKs — so there is no dashboard anywhere showing what you did. OCR runs on the device; images and text never leave the machine.

Yours to keep

Nothing sits behind a login only I control. Everything BarBox knows lives on your Mac in plain, standard places — drag the app to the trash and it is genuinely gone, no leftovers on a server.

Native, not wrapped

Swift and SwiftUI throughout, no Electron, no bundled browser — under a megabyte to download instead of three hundred. The App Store build runs fully sandboxed.

Open, so you need not trust me

The whole app is GPL-3.0 on GitHub — including every line of network code. Read it, or build it yourself with ./build.sh and compare. Copying and forking are welcome; please keep the attribution.

Build it yourself

Only the Xcode command line tools are needed (Swift 5.9+). There is no Xcode project — it is a Swift package.

git clone https://github.com/ipstyle/barbox.git
cd barbox
./build.sh
open build/BarBox.app
